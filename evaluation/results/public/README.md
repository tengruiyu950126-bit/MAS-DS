# Reviewed public evaluation results

These files are a curated, value-free subset of the five-seed MAS-DS
Multi-Expert evaluation. They contain aggregate labels, counts, and metrics only.
They contain no source dataframe cells, uploaded filenames, local paths, process
IDs, runtime logs, staging names, or per-row predictions.

- Evaluation schema: 1.0
- Seeds: 0, 1, 2, 3, 4
- Scenarios/routing runs: 110
- Ablation runs: 770
- Configurations: 7
- Result review date: 2026-07-21

See `docs/MULTI_EXPERT_EVALUATION.md` for definitions and threats to validity.
Confidence intervals in the source evaluation are normal approximations; this
curated summary makes no statistical-significance claim.
